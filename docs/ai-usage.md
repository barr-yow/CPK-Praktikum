## Contoh Prompt Kunci yang Digunakan

1. **Perancangan Arsitektur & Implementasi Kriteria 1–2**:
   > "Bantu buatkan struktur proyek Simple Messaging Application yang memisahkan frontend (HTML, pure CSS, native JS dengan fetch API) dan backend (native PHP + PDO MariaDB/MySQL) untuk fitur manajemen pengguna (register, login, delete account) dan CRUD kontak per pengguna, dengan format commit Conventional Commits."
2. **Penyesuaian Standar API & Keamanan Dasar**:
   > "Pastikan seluruh endpoint mengembalikan JSON yang konsisten, memvalidasi input, menggunakan password_hash/password_verify, serta membatasi akses CRUD kontak hanya pada pemilik akun yang terautentikasi."
